
# Smart Movie Recommendation System

## Project
DecodeLabs Artificial Intelligence Internship - Project 3

## Description
A content-based movie recommendation system that suggests movies according to user preferences.

## Features
- User name input
- Genre selection
- Minimum rating selection
- Similarity score calculation
- Personalized movie recommendations
- Recommendation summary table

## Technologies Used
- Python
- Streamlit
- Pandas

## Algorithm
Jaccard Similarity is used to compare user-selected genres with movie genres.

## How to Run

1. Install Python.
2. Install dependencies:

   pip install -r requirements.txt

3. Run:

   streamlit run app.py
